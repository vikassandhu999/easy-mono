03 / What stays separate

Four flows meet in the review.

The dashboard brings them together. Each still keeps its own meaning.

Agreed direction

Plan → expectation → actual record

Guidance for a date→What happened→Coach compares

Plan edits affect eligible subsequent activity. Already captured workout prescriptions and diary guidance stay frozen. Historical expectations still need new support.

PV4 · needs a precise rule

Record → reviewed version → correction

Coach sees version 1→Review saved→Version 2 stays new

A review covers information the coach considered. A later correction or unseen page must not be silently marked reviewed.

Proposed client experience

Review → feedback and current guidance

Private assessment + note→Optional chat reply+Focus + requests

Only the reply, current guidance, and review history are visible to the client. Sending a message alone does not complete a review.

Agreed report support

One report → grouped original files

PDF / photographed pages→One tracker entry→Coach inspects

Keep originals together. Jev AI extraction is future work. Structured results would live alongside those originals.
